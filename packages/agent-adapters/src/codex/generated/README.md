# Generated Codex app-server bindings

TypeScript types for the `codex app-server` JSON-RPC protocol, generated by the
Codex CLI itself. Do not edit by hand.

- Codex version: **codex-cli 0.158.0**
- Stable API surface only (no `--experimental`); the adapter does not opt into
  `capabilities.experimentalApi`.

## Regenerate

From the repository root, with the target `codex` on `PATH`:

```sh
rm -rf packages/agent-adapters/src/codex/generated/{*.ts,serde_json,v2}
CODEX_HOME="$(mktemp -d)" codex app-server generate-ts \
  --out packages/agent-adapters/src/codex/generated
```

Use a throwaway `CODEX_HOME` so generation never touches a real `~/.codex`.
Then update the version above, run `bun run typecheck` (the typed client in
`../rpc.ts` fails to compile if a method or field it uses changed) and
`bun test packages/agent-adapters`.

`biome.json` here excludes the generated `.ts` files from lint/format so they
stay byte-identical to the generator output.

Docs: https://learn.chatgpt.com/docs/app-server
